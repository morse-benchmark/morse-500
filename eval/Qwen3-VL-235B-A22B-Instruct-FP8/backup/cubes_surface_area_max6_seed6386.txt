We are given a 3D structure made of small cubes, each with side length 1 unit. We are to find the **total surface area** of the entire figure, counting only the **external** faces (i.e., faces not shared between two cubes).

---

### Step 1: Understand the structure

The structure is shown rotating in the video. It appears to be a 3x3x3 cube with some cubes removed — specifically, it looks like the center cube of each face and the very center cube of the 3x3x3 are removed. This is a classic “hollowed-out” 3x3x3 cube, often called a “skeleton” or “frame” cube.

Let’s verify:

- A full 3x3x3 cube has 27 small cubes.
- In the video, we can see that the center of each face is missing, and the very center cube is also missing.
- That’s 6 face centers + 1 very center = 7 cubes removed.
- So total cubes present = 27 - 7 = **20 cubes**.

This is consistent with the visual: we see a cube with holes in the center of each face and through the middle.

---

### Step 2: Calculate surface area

Each small cube has 6 faces. If all 20 cubes were isolated, total surface area would be 20 × 6 = 120 square units.

But when cubes are adjacent, they share faces, and those shared faces are **not** part of the external surface area.

So we must subtract **2 units** for every shared face (since each shared face hides one face from each of two cubes).

---

### Step 3: Count the number of shared faces

We need to count how many adjacent cube pairs there are — i.e., how many internal faces are shared.

Let’s analyze the structure:

The structure is a 3x3x3 cube with the center of each face and the very center removed.

We can think of it as the “shell” of the 3x3x3 cube, but with the very center cube also missing — so it’s like a 3x3x3 with all 7 “core” cubes removed.

Alternatively, we can count the number of shared faces by considering the structure layer by layer.

But perhaps a better approach is to **count the external faces directly** by examining each face of the entire 3x3x3 bounding box and seeing how many small faces are exposed.

Total possible faces if all cubes were separate: 20 cubes × 6 faces = 120.

Each corner cube is adjacent to 3 edge cubes (along the 3 edges it belongs to).

Each edge cube is adjacent to 2 corner cubes (at its ends) and possibly to other edge cubes? No — in a 3x3x3, the edge cubes are only adjacent to the two corner cubes on that edge, and possibly to face center cubes — but face center cubes are removed.

So, for example, take an edge cube on the top front edge. It is adjacent to the top-front-left corner and top-front-right corner. It is also adjacent to the face center cubes of the top face and front face — but those are removed. So it has only 2 neighbors: the two corners.

Similarly, each corner cube is adjacent to 3 edge cubes (one along each edge from that corner).

So let’s count total shared faces.

Each shared face is between two cubes. We can count the number of adjacent pairs.

Total number of adjacent pairs:

- Each of the 12 edge cubes has 2 neighbors (the two corners it connects). So 12 × 2 = 24, but each shared face is counted twice (once for each cube), so we must divide by 2? No — wait, no: if we count for each edge cube, the number of neighbors, and sum, we get the total number of “adjacent relationships”, which is equal to the number of shared faces.

Actually, yes: if cube A is adjacent to cube B, that’s one shared face. So if we sum over all cubes the number of neighbors, we get twice the number of shared faces (because each shared face is counted from both sides).

So let’s do that.

- Each corner cube has 3 neighbors (all edge cubes). There are 8 corners → 8 × 3 = 24.

- Each edge cube has 2 neighbors (the two corners). There are 12 edge cubes → 12 × 2 = 24.

Total sum of neighbors = 24 + 24 = 48.

Since each shared face is counted twice (once for each cube), the number of shared faces = 48 / 2 = **24**.

Therefore, total surface area = total faces - 2 × number of shared faces = 120 - 2 × 24 = 120 - 48 = **72**.

Actually, the structure is like a 3D cross: it has the 12 edge cubes and 8 corner cubes, forming a frame.

In such a structure, the internal surfaces are the faces that were facing the removed cubes.
