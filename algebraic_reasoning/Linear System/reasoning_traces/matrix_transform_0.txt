=== Problem Analysis ===
The video shows a linear transformation of the 2D plane.
We start with basis vectors i = [1, 0] (Green) and j = [0, 1] (Yellow).
We need to find the matrix M = [[a, b], [c, d]] that performs this transformation.

=== Key Insight ===
The columns of the transformation matrix correspond to where the basis vectors land.
Column 1 = M * [1, 0]^T = Transformed i vector
Column 2 = M * [0, 1]^T = Transformed j vector

=== Observation ===
1. The Green vector (i) moves to coordinates [-1, 1].
   Therefore, the first column is [-1, 1]^T.
2. The Yellow vector (j) moves to coordinates [-1, 0].
   Therefore, the second column is [-1, 0]^T.

=== Conclusion ===
Constructing the matrix from these columns:
[[-1, -1],
 [1, 0]]
