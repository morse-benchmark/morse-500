We are given a sequence of cubes, each with colored faces. The colors are defined as:
- Blue: cyan
- Red: red
- White: white
- Green: green
- Yellow: yellow
- Purple: purple

We are to count how many red faces are currently hidden from the camera.

Let’s examine each cube one by one, from left to right, and count the red faces that are not visible (i.e., hidden).

1. **First cube (leftmost):**
   - Visible faces: top (green), front (red), right (white)
   - Hidden faces: bottom (blue), left (purple), back (yellow)
   - Red face visible: 1 (front)
   - Red faces hidden: 0

2. **Second cube:**
   - Visible faces: top (yellow), front (white), right (purple)
   - Hidden faces: bottom (red), left (blue), back (green)
   - Red face visible: 0
   - Red faces hidden: 1 (bottom)

3. **Third cube:**
   - Visible faces: top (purple), front (blue), right (white)
   - Hidden faces: bottom (red), left (green), back (yellow)
   - Red face visible: 0
   - Red faces hidden: 1 (bottom)

4. **Fourth cube:**
   - Visible faces: top (white), front (red), right (yellow)
   - Hidden faces: bottom (blue), left (green), back (purple)
   - Red face visible: 1 (front)
   - Red faces hidden: 0

5. **Fifth cube:**
   - Visible faces: top (purple), front (white), right (green)
   - Hidden faces: bottom (red), left (blue), back (yellow)
   - Red face visible: 0
   - Red faces hidden: 1 (bottom)

6. **Sixth cube (rightmost):**
   - Visible faces: top (green), front (blue), right (yellow)
   - Hidden faces: bottom (red), left (white), back (purple)
   - Red face visible: 0
   - Red faces hidden: 1 (bottom)

Now, summing up the hidden red faces:
- Cube 1: 0
- Cube 2: 1
- Cube 3: 1
- Cube 4: 0
- Cube 5: 1
- Cube 6: 1

Total hidden red faces = 0 + 1 + 1 + 0 + 1 + 1 = 4

Thus, the number of red faces currently hidden from the camera is 4.

\boxed{4}
