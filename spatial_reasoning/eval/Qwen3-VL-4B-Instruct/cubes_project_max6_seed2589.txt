We are given a 3D structure composed of smaller cubes, and we are to find the maximum number of visible square faces in a parallel 2D projection, considering only the side faces (i.e., not the top or bottom faces).

### Step 1: Understand the structure
The structure is a 3D object made of smaller cubes. From the video, we can see that the structure is made of 27 smaller cubes arranged in a 3x3x3 cube. This is a standard Rubik’s cube structure.

### Step 2: Understand the projection
We are considering a parallel 2D projection. In a parallel projection, the projection direction is parallel to the viewing direction, and the projection is orthogonal (i.e., the projection is like a shadow cast by a light source parallel to the viewing direction).

In a parallel projection, we can see the front, top, and side faces of the structure, but not all of them simultaneously. The maximum number of visible faces in a parallel 2D projection is determined by the orientation of the object.

### Step 3: Consider the side faces only
The problem specifies that we are to consider only the side faces. This means we are to ignore the top and bottom faces.

In a 3x3x3 cube, there are 6 faces (front, back, left, right, top, bottom). If we are to consider only the side faces, we are to consider the front, back, left, and right faces.

### Step 4: Maximum number of visible side faces
In a parallel 2D projection, the maximum number of visible side faces is 4. This is because, in a parallel projection, we can see at most 4 side faces of a 3D object. For example, if we look at the object from the front, we can see the front face, and if we look at the object from the side, we can see the side face. But we cannot see all 4 side faces simultaneously in a parallel projection.

### Step 5: Conclusion
Therefore, the maximum number of visible square faces that can be seen in a parallel 2D projection, considering only the side faces, is 4.
